# Re:Solve Core UI Component Framework

Re:Solve requires a first-class, shared UI component framework for Admin, Client Portal, core modules, plugins and connectors.

Primary sources and influences are shadcn/ui, Untitled UI React, Tremor, React Aria/Base UI/Radix, TanStack Table and TanStack Query. Specialist libraries may be used when a documented workflow needs them.

The final product must look and behave like Re:Solve rather than a collection of unrelated libraries.
