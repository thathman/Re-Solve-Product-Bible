# Re:Solve Shell

Read the Core UI Framework and Navigation/Application Chrome specs first.

## Rules
- prioritize simplicity and obvious business labels;
- use clear persistent Admin left navigation;
- avoid app launchers, module grids, deeply nested trees and icon-only primary navigation;
- keep child pages inside area tabs/views;
- make Sidebar, TopBar, ResolveAvatar/AccountMenu, NotificationTrigger/Tray, Search/Command, Quick Create and Àríyá production-quality components;
- ensure phone/tablet navigation is deliberately recomposed;
- keep plugin extension slots controlled;
- preserve permission-aware route visibility plus server-side enforcement;
- represent foundational components/states in Component Gallery.

Stock starter-template shell quality is not completion.
