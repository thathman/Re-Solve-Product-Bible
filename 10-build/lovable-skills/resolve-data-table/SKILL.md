# Re:Solve Data Table

Use the Core UI Framework. Prefer TanStack Table or the stack's strongest compatible headless table engine.

Define as applicable:
- columns and priority;
- search;
- quick/advanced filters;
- sorting;
- saved/private/team/shared views;
- column visibility/pinning;
- selection and bulk actions;
- row action/open behavior;
- pagination/virtualization;
- stale/loading/empty/error states;
- permission-sensitive columns/actions;
- export permissions;
- keyboard/focus behavior;
- mobile alternate row/card/detail representation.

Do not squeeze a desktop table onto a phone. Use a specialist enterprise grid only when the workflow genuinely requires spreadsheet/grid behavior.
